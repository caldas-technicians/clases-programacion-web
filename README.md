# Material de Estudio y Práctica para Programación Web Creativa II

Ejercicios y guías de clase construidos con HTML, CSS y JavaScript sin frameworks.

## Contenido

| Sesión | Carpeta | Tema |
| --- | --- | --- |
| 1 | `session-1/ejer-01` | Laboratorio del DOM: seleccionar, modificar, crear y eliminar elementos |
| 1 | `session-1/ejer-02` | Festival del Mundo: selectores, atributos y BOM |
| 2 | `session-2/ejer-01` | Tarjetas de cursos: crear tarjetas, formulario, favoritos y eliminar |
| 3 | `session-3/ejer-01` | Menú responsive accesible con eventos |
| 3 | `session-3/guias/taller-clase.md` | Guía: eventos paso a paso |
| 5 | `session-5/guia-1/guia.md` | Guía: formularios y validación paso a paso |

## Cómo usar

1. Abrir la carpeta del ejercicio en el editor de código.
2. Abrir `index.html` en el navegador (o con una extensión tipo *Live Server*).
3. Leer los enunciados en los comentarios del archivo `.js` y resolverlos.
4. Mantener la consola abierta (`F12`) para revisar errores y resultados.
